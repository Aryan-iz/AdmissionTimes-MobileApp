# Mobile App Overview

## Scope

This mobile app currently delivers the student module only.

## Core User Journeys

- Student authentication
- Dashboard and recommendations
- Search and program detail
- Watchlist and compare
- Deadlines and notifications
- AI chat assistant

## Architecture Summary

- React Native + Expo
- TypeScript
- Zustand stores
- Axios service layer
- Supabase session/auth integration
- Backend API for business data

## Out of Scope (Current Phase)

- Admin mobile module
- University representative mobile module
